Writing Sophisticated Applications

Smalltalk-2026 comes with this basic running application. Since the front-end and back-end can be changed while the system is running, the idea is that a developer starts with this basic application and builds it into the desired application.

The basic application the system comes with does not represent the kind of application that can be built with Smalltalk-2026. It is intentionally kept basic so that it is easy to see how it works. In a real application, all the possibilities made available with HTML and CSS are at your disposal without limitation. In other words, the only limitations to the sophistication of the application are your imagination and the amount of work you're willing to put into it.

Smalltalk-2026 comes with a complete front-end framework that includes most of the things needed for a modern business web application. However, there is nothing in Smalltalk-2026 that prevents you from using other front-end frameworks such as React, Angular, Vue, etc. In fact, except for dealing with web services and authentication, you could exclusively use your preferred front-end framework.

The Smalltalk-2026 back-end is a complete back-end: an HTTP server that runs one request per core, sessions, one database transaction per request, and web services that are Smalltalk classes in files, read into the running image the first time a request names them and read again when they change. A web service is a single source file containing just a handful of lines of code, and it can be edited while the server runs. Everything in Smalltalk-2026 is designed to be simple to understand and simple to use.
