# Licensing

Three bodies of source live in this repository and they are not under the same
terms. Which directory a file is in tells you which apply.

| directory | origin | licence |
|---|---|---|
| `src/`, `lib/`, `tests/` (with `tests/bench/`), `tools/`, `manual/`, `profiles/`, `doc/` | written for this project | BSD-2-Clause, © 2026 Blake McBride — the text is in `LICENSE` at the root |
| `sources/` | Smalltalk-80 v2 sources, Mark Bush's transcription | MIT |
| `pharo/` | imported from the Pharo project | **MIT, with parts under Apache-2.0** |
| `demo/` | the project's own back end and pages, plus third-party files | BSD-2-Clause for the project's files; `demo/frontend/PROVENANCE.md` records the rest, among them `ckeditor.js` (GPL-2.0-or-later or commercial) |

## `sources/` is frozen

Nothing in it is ever edited. Every divergence from 1983 is a new file in `lib/`.
That is a licensing convenience — the transcription stays verbatim and attributable —
and, more importantly, it is what makes "how far have we drifted" a question with a
mechanical answer.

## `pharo/` — imported, attributed, and recorded

Pharo is distributed under the MIT License **with parts under the Apache License**;
its own `LICENSE` says so in its first line. Every imported file keeps whatever notice
it arrived with, and every package directory carries a `PROVENANCE.md` recording:

- the upstream repository and the exact commit,
- the licence as the upstream states it,
- the files taken, and any file deliberately **not** taken,
- **every local edit**, line by line.

The last of those is the one that matters. A package that has been quietly patched is
a package nobody can update, and the whole point of importing rather than rewriting is
that upstream keeps improving. If a change is needed, it goes in the provenance file
before it goes in the source.

## The built-in face — SIL Open Font License 1.1

The system has to draw text and the 1983 sources carry no font data: fonts
lived in the image, and the image is the one thing here that has no licence.
So `src/gfx/font_face.c` and `font_face.h` are a **rasterisation of an outline
font**, generated by `tools/make_font.py`, currently **Inter at 18 pixels**.

The font itself is **not vendored**. The generator runs against a font already
installed on the machine and only its *output* is checked in. That output
records the source file's path, name, size, leading and **SHA-256**, so which
font produced it is not a matter of memory — `Inter` is not one font, and two
versions of a family rasterise differently at the same size.

What that means in practice:

- **Building this system needs no font and no Python.** The tables are ordinary
  checked-in C. `make font` is only for changing the face.
- The tables are a **derivative work** of an OFL-1.1 font. `src/gfx/LICENSE.font`
  is that licence, copied verbatim from the package the font came from, and it
  travels with this repository.
- OFL's Reserved Font Name clause is not engaged and could not be: these tables
  are ninety-five pictures of letters at one size. Nothing here is a font file
  and nothing here can be installed as one, so there is no font to misname.
- OFL permits bundling a derivative with software under any licence, which is
  why the rest of the tree stays BSD-2. The obligation is to keep the licence
  with the derivative, and that is what `LICENSE.font` is for.

If you regenerate from a **different** font, replace `src/gfx/LICENSE.font` with
that font's licence and check it permits what you are doing. The generated
header will name the new font and hash it, but it cannot know the terms.

## Binary distributions

A binary distribution (`Distributions.md`) is not the source tree, and this
file is not what it ships. It carries `tools/dist/LICENSING.md`, which
describes what is in the distribution, and a `licenses/` directory with the
texts the parts that are other people's require to travel with them:

- `LICENSE.font` — `src/gfx/LICENSE.font`, because the face tables are
  compiled into the binary;
- `LICENSE.smalltalk-80` — `sources/LICENSE`, Mark Bush's MIT notice,
  because the 1983 class library is compiled into the image, and MIT asks
  for the notice in every copy;
- a directory per bundled library — SDL3 (zlib), unixODBC and libltdl
  (LGPL-2.1-or-later) on Linux, whatever Homebrew libraries macOS needs,
  SDL3 and OpenSSL (Apache-2.0) on Windows — holding the licence text
  found where the library's package put it, and `BUNDLED.md` listing each
  one with its version and where its source is.

`pharo/` and `demo/` are not in a distribution, and neither is their
licence. The release recipe (`tools/dist.sh`, `Makefile.msvc`'s `dist`)
stops when it cannot find the licence of a library it bundles.

## Copyright notices in imported files

Pharo's Tonel files do not carry per-file copyright headers; the notice lives in the
repository's `LICENSE`. Copying that convention is what "keeps its notice" means here,
so `pharo/LICENSE.pharo` holds the upstream text verbatim and each `PROVENANCE.md`
points at it. Adding a per-file header would be *changing* the notice, not preserving
it.
